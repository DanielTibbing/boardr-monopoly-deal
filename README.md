# Monopoly Deal — a boardr game

The fast, brutal card game of building property sets and raiding your rivals. Bank money, lay properties, and hit opponents with Rent, Debt Collector, Sly Deal, Forced Deal, and Deal Breaker — then Just Say No when they come for you. First to three complete sets of different colours wins. 2–5 players; hands stay secret on phones, banks and properties show on the table.

Built with [@boardr/sdk](https://www.npmjs.com/package/@boardr/sdk) for the [boardr](https://danieltibbing.github.io/boardr-community-contribs/) digital boardgame table.

Core version: House, Hotel, and Double the Rent are deferred to a follow-up.

## Develop

```sh
npm install
npm run build
npm test
npx boardr dev
```
